> PROJECT VISION & TARGET GOALS

Traditional resume portfolios are inherently static. They list skills, but fail to demonstrate an engineer’s real-world communication logic or interactive engineering depth.

// THE CORE UX CHALLENGE

Design a zero-latency system portal using high-fidelity hacker console mechanics. Convert the visitor from a passive viewer to an active system operator interacting directly with pre-trained query nodes.

Target Audience Behavior

CTOs, Engineering Managers, and Recruiters budget roughly 10 seconds per resume. The UX must provide immediate proof of skill through zero-latency tactile controls, direct terminal command execution, and real-time auditory visuals.

> DESIGN SYSTEM & VISUALTOKENS

The aesthetic is heavily inspired by classic CRT shell designs, green/cyan phosphor screens, and high-contrast diagnostic HUD grids.

  • Matrix HSL Variables: Responsive green/cyan matrices designed to adapt dynamically. Matrix green matches the base terminal state; cyan matches active AI queries.
  • CRT Visualizers: Faint CSS-pattern scanlines, CRT vignetting overlays, and glowing canvas components create structural depth.
  • System Fonts: Share Tech Mono forms the command lines. Rajdhani handles structural dashboard cards.
